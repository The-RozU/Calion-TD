# Calion Tower Defence

Gra tower defence osadzona w świecie Calionu. Dwie misje w jednym samodzielnym pliku HTML.

## Wersja 0.0.2

Przeniesienie prototypu z gałęzi `tower-defence` repozytorium `The-RozU/Calion` do osobnego `The-RozU/Calion-TD` na gałąź `dev-mode`. Mechaniki i misje zachowane.

## Uruchomienie

Otwórz `index.html` lokalnie w przeglądarce. Po włączeniu GitHub Pages pod adresem https://the-rozu.github.io/Calion-TD/ gra będzie dostępna online.
